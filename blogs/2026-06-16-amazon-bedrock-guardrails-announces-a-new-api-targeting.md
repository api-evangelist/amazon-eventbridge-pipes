Amazon Bedrock Guardrails now offers the InvokeGuardrailChecks API, a resourceless API that applies individual safeguards at any point in agentic AI applications without creating guardrail resources. It returns numeric severity and confidence scores and supports content filters, prompt attack detection, and sensitive information filters across seven AWS Regions.
