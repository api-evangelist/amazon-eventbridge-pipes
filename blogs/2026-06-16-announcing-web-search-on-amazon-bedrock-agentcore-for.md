Web Search is now generally available on Amazon Bedrock AgentCore, enabling agents to ground responses in current web knowledge while maintaining data residency within secured AWS environments with zero data egress. Built on Amazon's search infrastructure, it combines web indexing with structured knowledge graph data and is available in US East (N. Virginia).
