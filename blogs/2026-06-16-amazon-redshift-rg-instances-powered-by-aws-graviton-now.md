Amazon Redshift expands RG instances powered by AWS Graviton to Africa (Cape Town), Asia Pacific (Bangkok), and Mexico (Central). These instances deliver up to 4.2X better price-performance, run 2.4x faster than RA3 instances, and cost 30% less per vCPU, including incremental manual snapshots and no Redshift Spectrum scanning charges.
